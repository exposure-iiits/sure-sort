# Sure Sort 0.1.4 — footer copy toggles

Click a footer folder or press its primary/alternate shortcut to copy the current photo there. Folders containing that photo have a green outline. Click or press the same shortcut again to remove that destination’s copy; removal keeps the photo selected. A second press while saving cancels the pending copy.

The visible photo bends and narrows into the chosen folder with a short genie animation. Navigation advances immediately, saving stays in the background, and rapid sorting keeps at most one animation on screen. The animation uses the photo selected before auto-advance.

The separate Manage copies dialog and extra footer status row are replaced by the existing folder controls. Folder tooltips describe copy, cancel, removal, or errors. Ctrl+Z, folder counts, green thumbnail outlines, per-folder progress and original-file protections remain available.

Version 0.1.4 is shown in About, --version and Windows executable properties. Existing copy-only progress files continue to work.

Portable app: `dist/Sure Sort 0.1.4 Genie/Sure Sort.exe`.
Archive: `dist/Sure-Sort-0.1.4-Windows-x64-Genie.zip`.
