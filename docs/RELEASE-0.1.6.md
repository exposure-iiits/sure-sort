# Sure Sort 0.1.6

Watermark settings now follow you across photo folders, including previously opened folders, and survive restarting the app. The app profile keeps the latest logo and settings. Each queued copy keeps the watermark captured when it was assigned.

While adjusting watermark Size, Opacity or Padding, the entire Settings window becomes transparent immediately on pressing the slider and returns to normal immediately on release. Keyboard adjustments follow key press/release; touchpad scrolling follows its gesture. Switching pages or closing Settings restores normal opacity immediately. Settings saves are debounced to keep adjustments responsive.

Quick editing settings use shorter text. Keyboard shortcuts now contains Navigation, Viewing and Editing. Fit, Clear latest placement and Skip photo are hidden, and the Sorting and Application tabs are removed. Their existing keyboard actions continue working. Folder shortcuts remain available in Settings → Sorting.

PNG logos no longer have a 16 MP limit. The 16 MiB PNG file-size limit remains.

Destination toasts display only the destination folder name. The footer no longer shows F Fit. The application uses the Sure Sort logo for its taskbar/window icon instead of a transparent icon.

Run `dist/Sure Sort 0.1.6/Sure Sort.exe` or extract `dist/Sure-Sort-0.1.6-Windows-x64-Portable.zip`.
