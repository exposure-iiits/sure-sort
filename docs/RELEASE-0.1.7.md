# Sure Sort 0.1.7

## Folder setup

- Click the output path and choose **Create [opened folder]_sorted** to create and select an output folder beside the original folder. An existing directory is reused without overwriting its contents.
- Right-click a footer folder and choose **Remove** to remove its button and shortcut. Its directory, files, pending copies and saved copy records are preserved, and the button stays removed after reopening.
- Folders without saved progress offer **Reuse folders** and **New folder**. Reuse previous destination names, or read immediate subfolder names from another directory. Available number shortcuts are assigned automatically. Existing folder sessions still restore their own setup.

## Keyboard shortcuts

The keyboard button now opens a compact panel in the viewer, matching the edit panel's size and typography. Click keycaps to customize bindings. Arrow and other key symbols make combinations easier to scan. Long combinations wrap into taller rows, with vertical scrolling and no horizontal scrolling. Opening Edit switches back to the edit panel.

## Planned updates

Startup update checks with an **Update / Later** prompt are documented in [the roadmap](ROADMAP.md). The intended flow downloads an installer after consent, saves the current session, installs, and restores the work on reopening. Automatic updating is **not implemented in this release**.

Windows x64 installer and portable ZIP packages are provided. macOS remains experimental and has no new binary package in this release. Original photos and existing saved sorting sessions remain intact.
