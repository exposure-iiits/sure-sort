# Sure Sort 0.1.2

- The header Settings and Shortcuts buttons return to the photo screen when clicked while their own panel is already open. Clicking the other button switches panels. Version remains 0.1.2.
- Footer Plus opens a focused name field styled like the destination buttons. Enter or leaving the field saves; Esc cancels.
- New folders use Move and the next available number key, followed by modifier-number keys when needed. Existing Copy/Move choices are retained.
- With no output folder configured, Plus opens Settings → Sorting. Choose the output directory and Save folders, then add your destinations.
- Double-click a Primary or Alternate shortcut cell and press the replacement key or chord. Changes save immediately. Esc cancels and Delete unassigns. Conflicts produce a temporary toast and preserve the previous binding.
- Editing chords can be recorded by holding a letter and pressing a trigger. Primary and Alternate editing shortcuts share the action's hold key.
- Shortcut categories have a stronger selected background and underline. Editing shortcuts opens Editing directly. Removed pencil controls and instructional text from the shortcut panel.
- The header and native Windows title bar show the Sure Sort name without a logo. The executable file retains its icon.
- Rotation uses a −180° to +180° slider with one-degree increments, a live value and double-click reset. Legacy quarter-turn edits remain readable.
- Version 0.1.2 in About, command-line output, Windows executable properties and installer. Session schema remains 7.
