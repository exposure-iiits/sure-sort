# Sure Sort 0.1.5

Click the output path in the header to open its folder in Explorer or choose a different output location. Completed copies retain their recorded paths when the output location changes.

Folder buttons scroll horizontally when the footer fills. Use the mouse wheel, trackpad or scrollbar. Copying with a shortcut brings its animation destination into view.

Settings → Viewing → Show destination folder toast after copying displays the photo and destination name only after successful copying. It is off by default and saved between sessions.

Sorting Undo is removed completely, including its button, Ctrl+Z action, controller logic and persistent history. Existing copy-only progress loads normally; schema 2 discards the old Undo table while keeping assignments and edits. Folder buttons still toggle individual copies safely.

Run `dist/Sure Sort 0.1.5/Sure Sort.exe` or extract `dist/Sure-Sort-0.1.5-Windows-x64-Portable.zip`.
